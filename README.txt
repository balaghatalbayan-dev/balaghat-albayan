بلاغة البيان للتسويق — حزمة الموقع الأولية
===========================================

المحتويات:
- index.html: صفحة الموقع العربية.
- style.css: التصميم المتجاوب للكمبيوتر والجوال.
- script.js: قائمة الجوال وسنة حقوق النشر.
- assets/logo.png: الشعار المستخدم في التصميم.

قبل النشر:
1. افتح index.html في المتصفح لمعاينة الموقع.
2. راجع الخدمات المكتوبة وعدّل ما لا يطابق خدمات الشركة الفعلية.
3. راجع رقم واتساب ورابطه في index.html (حاليًا: +966536595401).
4. لا تضف عنوانًا أو بريدًا إلكترونيًا إلا إذا كانت بياناتك مؤكدة.

النشر المجاني:
يمكن رفع محتويات هذا المجلد إلى مستودع GitHub ثم تفعيل GitHub Pages من Settings > Pages.
هذه نسخة تصميم أولية؛ النطاق المخصص مثل .com قد يحتاج شراءً منفصلًا.
